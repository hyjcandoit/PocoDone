# Views, formulas & progress math — v2

## 推荐视图

| 视图 | 实际筛选 | 排序 | 常用列 |
|---|---|---|---|
| 原始任务表 | 无筛选 | 日期 ASC | 任务、日期、优先级、状态、执行说明 |
| ✅ 每日任务｜点击已完成自动联动 | `分类 = 每日计划` AND `所属进度 IS NOT EMPTY` | 日期 ASC | 任务、日期、状态、所属进度 |
| 📍 未完成每日任务 | 每日分类 + 已关联 + `状态 != 已完成` | 日期 ASC | 任务、日期、状态、所属进度 |
| 📅 动态本周进度 | `进度追踪 = true` AND `本周重点 = true` | 展示序号 ASC | 任务、进度条、逾期提示、日期 |
| 📆 本月进度｜含遗留 | **当前实践**：`进度追踪 = true` | 展示序号 ASC | 任务、进度条、逾期提示 |
| 🚨 逾期待办 | `状态 = 逾期待办` | 日期 ASC | 任务、状态、逾期提示、日期、所属进度 |
| ➕ 新建任务｜样板 | `任务 CONTAINS 【模板样板】` | 任务 ASC | 任务、任务类型、分类、执行说明 |

**谨慎命名**：当前“本月进度”实际会纳入**所有 `进度追踪=true`** 的父任务：包括当前月、上月未完成、当前月已完成，以及未来月份预先勾选的父任务。它不是真正的月份过滤器；使用者不能把图表标题当作过滤逻辑。要实现真正的动态月份，应增加 `本月展示` Checkbox 并由任务调度更新，或在 Notion 原生视图配置适当的日期/公式筛选并确认真实生效。

视图中的 `本周重点` 也**不会因为周一到来自动勾选**。若没有自动任务，只能手动更新。

## 公式示例（Notion Formula 2.0）

### 步骤完成

```notion
prop("状态") == "已完成"
```

### 步骤完成率（Rollup）

- Relation: `每日步骤`
- Target property: `步骤完成`
- Calculate: `Percent checked`
- 返回 0~1 的比例数值，而不是 0~100。

### 进度百分比

以下对应生产实践的兼容公式。`每日步骤` 非空时优先使用关联 rollup。旧阶段勾选字段只在无子步骤时提供进度；不需要旧兼容字段的新用户可删去中间两支并改为 `if(prop("状态") == "已完成",100,0)`。

```notion
if(
  length(prop("每日步骤")) > 0,
  round(prop("步骤完成率") * 100),
  if(
    prop("进度类别") == "CS50P",
    if(prop("课程学习完成"), 50, 0) + if(prop("PSet提交完成"), 50, 0),
    if(
      prop("进度类别") == "文书",
      if(prop("大纲完成"), 25, 0) +
      if(prop("第一版完成"), 25, 0) +
      if(prop("第二版完成"), 25, 0) +
      if(prop("第三版完成"), 25, 0),
      if(prop("状态") == "已完成", 100, 0)
    )
  )
)
```

**重要边界**：若“简单任务”被误选为 `进度类别=文书` 但没有每日步骤，即使 Status 已完成，也会优先走四个历史 Checkbox 的计算；模板默认选 `其他`，以免该误差。

### 文字进度条

```notion
repeat("█", floor(prop("进度百分比") / 10)) +
repeat("░", 10 - floor(prop("进度百分比") / 10)) +
" " + format(prop("进度百分比")) + "%"
```

### 自动逾期（Boolean）

```notion
if(
  empty(prop("日期")),
  false,
  and(
    dateEnd(prop("日期")) < today(),
    prop("状态") != "已完成",
    if(prop("进度追踪"), prop("进度百分比") < 100, true)
  )
)
```

该公式提供**逾期布尔判断**，不会自行把 Status 改成红色。单日 `日期` 如果在该工作区代表“计划开始日期”而非截止日，可能被误判，应先明确 `日期` 含义。

### 逾期提示（String）

```notion
if(prop("自动逾期"), style("🔴 逾期待办｜请抓紧处理", "red", "b"), "")
```

### 自然周判定（可选辅助公式）

```notion
if(
  empty(prop("日期")),
  false,
  and(
    dateStart(prop("日期")) <= dateAdd(dateSubtract(today(), day(today()) - 1, "days"), 6, "days"),
    dateEnd(prop("日期")) >= dateSubtract(today(), day(today()) - 1, "days")
  )
)
```

**注意：**Notion `day()` 以周一为 1、周日为 7 的语义需在你的实际 Formula 版本中确认。日期/时区和 API 筛选能力在不同连接器中可能不同，无法保存筛选时应回退到 `本周重点` Checkbox + 经授权的每日整理，而不要宣称原生动态。

## 图表统计的真实含义

- `📊 本周完成率`：对符合 `进度追踪=true AND 本周重点=true` 的**父任务**计算 `进度百分比` 的简单平均。
- `📊 本月整体完成率`：如果只筛 `进度追踪=true`，则对全部追踪父任务取平均；不是限定自然月，更不是耗时加权。
- `📊 各项目进度对比`：按 `进度类别` 分组，使用父任务完成率的简单平均。
- 当给某个老任务添加新子任务（分母变化）时，图表平均值可能变化，不能误认为用户“退步”。

## 排序建议

`展示序号` 可以使用数值区间表达分类和顺序：比如 10–99 课程、110–199 文书、210–299 AI、900+ 历史逾期。**这些仅是示例约定，不是 Notion 强制规则**；用户新增项目时可修改而不影响 Relation。
