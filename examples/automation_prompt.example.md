# 可选：已授权的每日周计划整理提示词

> 此文件仅是提示词示例，不包含已启用的定时任务；用户必须另外连接 Notion、设置排程和时区后才可能执行。

```text
在我授权的 Notion 任务数据库中整理当天任务。
使用我的时区 [IANA_TIMEZONE] 计算今天及当前周一到周日。
先读取实际数据库 schema、任务状态、父子关系与视图，不创建新数据库。

对于进度追踪为 true 的真实父任务：
- 如果日期区间与本自然周相交，或者原截止日已经过去且父任务实际尚未完成，把“本周重点”设为 true。
- 其他真实父任务是否清除“本周重点”，须检查它们是否属于长周期活跃项目；模板样板不参与。
- 对日期已过、状态尚未“已完成”的父任务与日任务，标记红色“逾期待办”，不把进行中/待开始误判为已完成。
- 父任务子任务全部已完成但 Status 未更新时，标记待复核，不重复添加逾期项。

不得重复创建子任务；不得修改已完成记录、覆盖旧进度、替换真实截止日、删历史行。
保持“展示序号”顺序，核对每日/周/月/逾期待办视图仍能查询。
输出本次新增/修改/跳过数量，最紧急的 1–3 个逾期项目，并说明异常。
如果没有访问或写入权限，明确报告未执行，而不是猜测已同步。

重要：不启用“新建大型任务自动 AI 拆分”。
```
